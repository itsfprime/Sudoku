# Sudoku - A project in DFS

## How To Play:
Upon opening the game, a puzzle is ready for you to solve. If you wish to play another puzzle, press the "New Puzzle" button.

### Placing values:
* Select a value by either pressing a key 0-9, or clicking a value 0-9 on the rightmost panel on the screen, the "Candidates Panel". Selecting a value other than 0(X) will highlight all cells with that value on the board in blue.
* Click on any cell to place the currently selected value inside it
* If a cell's text is red, that means the value in that cell is incorrect, and the mistakes counter will increment.

### Auto candidates feature:
Checking the auto-candidates box will visualize all the possible candidate values of each cell on that cell if there is no value in that cell.
